# Data

The raw dataset is **not committed to this repository** (large file, separately licensed) —
place it here before running the notebook locally.

| File | Where to get it |
|------|------------------|
| `city_day.csv` | Download from [Kaggle — Air Quality Data in India (2015–2020)](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india) and save it as `data/city_day.csv` |

On Kaggle (the recommended way to run this project — see the main [README](../README.md#how-to-run)),
the dataset is already attached and the notebook auto-detects the Kaggle input path, so this
folder is only needed for a local run.

The pre-aggregated outputs derived from this file (tables, figures, and the Power BI dataset)
are already committed under [`../tables/`](../tables), [`../figures/`](../figures), and
[`../powerbi/dataset/`](../powerbi/dataset) — you don't need the raw CSV just to view results.
